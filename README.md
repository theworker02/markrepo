# markrepo

Mark CSV/TSV repo tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/markrepo/

## Install / run

```bash
git clone https://github.com/theworker02/markrepo.git
cd markrepo
node src/cli.js
node --test
```
